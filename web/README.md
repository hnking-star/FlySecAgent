# Web 黑板

服务启动后打开：

```text
http://127.0.0.1:8787/web/
```

页面会要求输入 `data/.secret` 中的本机访问令牌。令牌只保存在当前页面内存中；刷新或点击“锁定”后需要重新输入。

页面是一个响应式只读安全工作台，包括：

- 项目概况、观察状态、判断/API 数量和窗口处理位置。
- 从“测试目标”开始、按 `dependsOn` 分层连线的探索图，以及判断、尝试和证据详情。
- 可搜索并按测试状态筛选的 API 台账。
- 分栏展示的工具输入、工具结果和元数据。
- Observer 日志、短反馈、历史版本和可复制的 Markdown 报告。

“刷新”会同时同步最新项目列表和当前黑板。所有模型和工具文本都通过 DOM `textContent` 渲染，不执行其中的 HTML 或 JavaScript；页面不加载任何外部资源。
