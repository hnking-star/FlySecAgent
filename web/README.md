# Web 黑板

服务启动后打开：

```text
http://127.0.0.1:8787/web/
```

页面只监听本机 `127.0.0.1`，直接打开即可查看，不需要输入访问令牌。Hook、Control 和 Observer 接口仍使用原有 token 鉴权。

页面是一个响应式只读工作台，默认进入项目列表；带 `?session=<会话ID>` 的链接直接进入对应项目详情。

## 项目列表

- 按名称、测试目标、会话 ID 或测试目的搜索。
- 筛选观察开启、Observer 暂停、观察关闭和尚未发布的项目。
- 按创建时间或测试目标排序；侧栏可快速进入最近项目。
- 显示观察状态、主 Agent 回合状态、黑板版本、处理位置和发布时间。
- 统计基于接口返回的已加载项目（当前上限 200 条），不是数据库全量统计。
- 点击项目进入详情；返回列表和浏览器前进/后退均可导航。

第一版仍然只读：不创建、删除项目，也不暂停、恢复或关闭观察。项目仍由 Agent / Hook 创建。

## 项目详情

详情分为“探索图”“API 台账”“证据与反馈”三个页签，包括：

- 项目概况、观察状态、判断/API 数量和窗口处理位置。
- 从“测试目标”开始、按 `dependsOn` 分层连线的探索图；节点详情同时显示该节点 `apiIds` 关联的 API、历史测试、判断尝试和证据。
- 单行折叠式 API 台账：默认一接口一行，点击后展开参数、测试动作、结果与证据，并支持搜索和测试状态筛选。
- 分栏展示的工具输入、工具结果和元数据。
- Observer 日志、短反馈、历史版本和可复制的 Markdown 报告。

点击节点或 API 中的证据会自动切换到“证据与反馈”。切换项目时会清理旧详情，晚到的异步返回不会混入新项目。

图中的“有进展”表示测试取得信息或进展，不等于确认漏洞；有 API 测试记录也不代表全面覆盖。

“刷新”会同时同步最新项目列表和当前黑板。所有模型和工具文本都通过 DOM `textContent` 渲染，不执行其中的 HTML 或 JavaScript；页面不加载任何外部资源。
